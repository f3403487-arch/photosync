# PhotoSync 📲↔💻

Перекидывает фото и файлы между Android-телефоном, компьютером на Windows и планшетом. Без облаков, проводов и аккаунтов: дома по Wi-Fi, вне дома через зашифрованный ретранслятор.

## Что умеет

- **Телефон → ПК:** выбираешь фото или файлы, они падают в папку на компе.
- **ПК → телефон:** правый клик по файлу → «Отправить» → «PhotoSync — на телефон», или просто `send_to_phone.bat файл`.
- **Телефон → планшет:** на втором Android-устройстве включаешь «Приём».
- **Не дома:** если телефон и комп в разных сетях, файлы идут через публичный ретранслятор [ppng.io](https://ppng.io). Перед отправкой они шифруются (HMAC-SHA256 CTR + проверка целостности), ключ знают только твои устройства, и передаётся он один раз по домашнему Wi-Fi. Скорость там 0.1–0.5 МБ/с, так что вне дома лучше для фото, а не для фильмов.
- **Обходит VPN:** если на телефоне включён VPN, локальные соединения всё равно идут напрямую через Wi-Fi.
- **Дружит с [Clawd](https://github.com/f3403487-arch/clawd-pc):** если рядом запущен Клодик, он прибегает с файлом, когда тот приходит, и убегает с ним, когда отправляешь.

## Установка

### Телефон

Скачай `PhotoSync.apk` из [Releases](../../releases) и установи. Android попросит разрешить установку из неизвестного источника.

Если Chrome или Play Защита предупредят об опасном файле: так они реагируют на любой APK не из Play Маркета. Жми «Всё равно скачать» / «Всё равно установить». Если Play Защита предложит отправить приложение на проверку, соглашайся, после этого предупреждение пропадает.

### Компьютер

Нужен Windows 10/11 и [Python 3.10+](https://www.python.org/downloads/). Сторонние библиотеки не нужны.

```bat
git clone https://github.com/f3403487-arch/photosync.git
cd photosync\pc
start_pc.bat
```

При первом запуске комп покажет **код сопряжения**, его нужно ввести на телефоне. Если Windows спросит про брандмауэр, разреши доступ в частных сетях (порт TCP 8765).

Принятые файлы сохраняются в папку `С телефона` в профиле пользователя.

### Отправка с ПК на телефон

На телефоне включи «Приём». Потом на компе:

```bat
send_to_phone.bat фото.jpg документ.pdf
```

Ярлык на `send_to_phone.bat`, положенный в `shell:sendto`, добавит пункт в меню «Отправить» у любого файла.

## Сборка APK самому

Нужны JDK 17, Android SDK (platform 34) и Gradle 8.7, Android Studio не обязательна:

```bat
cd android
echo sdk.dir=C\:\\путь\\к\\Android\\Sdk> local.properties
gradle assembleDebug
```

APK окажется в `android/app/build/outputs/apk/debug/`.

## Безопасность

- Код сопряжения и ключ ретранслятора лежат в `pc/photosync_config.json` и `pc/sender_config.json`. У каждой установки они свои. Эти файлы в `.gitignore`, не публикуй их.
- По локальной сети файлы идут без шифрования, но комп принимает их только с правильным кодом.
